# Сайт-приглашение на 50-летие 🎉

Одностраничный мобильный сайт-приглашение на **50 жас мерейтойы**:
текст приглашения, календарь, обратный отсчёт, карта, RSVP-форма (сохранение
ответов гостей в Google-таблицу), фоновая музыка.

Языки: казахский / русский (переключатель в правом верхнем углу).

---

## 📖 Как редактировать сайт

Все главные настройки собраны в одном месте — в блоке `CONFIG` в самом начале
`<script>` внутри файла `index.html`.

| Что меняем | Где |
|---|---|
| Дата и время юбилея | `CONFIG.eventDate`, `CONFIG.calYear`, `CONFIG.calMonth`, `CONFIG.calDay` |
| Адрес / карты | `CONFIG.googleEmbed`, `CONFIG.googleLink`, `CONFIG.twogisLink` и карточка «Мекенжай» |
| Текст приглашения | блок `<section>` с `serif-body` (комментарии «КАЗАХСКИЙ ТЕКСТ» / «РУССКИЙ ТЕКСТ») |
| Имя юбиляра | места с надписями «50 жас» / «50 жас мерейтойы» (поискать `50 жас`) |
| Музыка | положить файл в `music/` и указать путь в `CONFIG.music` |

> Календарь, месяц и время берутся из `CONFIG` автоматически — достаточно
> поменять дату в одном месте.

## 🗒️ Новая Google-таблица для ответов гостей (RSVP)

Сайт отправляет ответы гостей в Google-таблицу через Google Apps Script.
Чтобы привязать **свою** таблицу, выполни шаги ниже.

### Шаг 1. Создай таблицу
1. Открой адрес **https://sheets.new** (создастся новая пустая таблица).
2. Переименуй лист в **«Ответы»** (двойной клик по названию листа внизу).
3. В первой строке запиши шапку: `Дата ответа`, `Имя гостя`, `Ответ`.

> Шапка не обязательна, но с ней удобнее читать таблицу.

### Шаг 2. Добавь скрипт
1. В меню таблицы открой **Расширения → Apps Script**.
2. Удали текст из редактора и вставь этот код:

```js
function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.tryLock(10000);
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const sheet = ss.getSheetByName('Ответы') || ss.insertSheet('Ответы');
    const data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      new Date(),
      data.fullName,
      data.attending ? 'Приду (келемін)' : 'Не смогу (келе алмаймын)'
    ]);
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'ok' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: 'error' }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

### Шаг 3. Разверни как веб-приложение
1. В Apps Script нажми **Развертывание → Новое развертывание**.
2. Рядом с шестерёнкой выбери тип **Веб-приложение**.
3. Поля заполни так:
   - **Описание**: `RSVP`;
   - **Выполнять от имени**: `Я` (твой аккаунт);
   - **Доступ для** — обязательно **«Все, у кого есть ссылка»**.
4. Нажми **Развернуть** и при запросе **«Разрешить доступ»** нажми
   «Предоставить доступ» (это нужно один раз).
5. В открывшемся окне скопируй **URL веб-приложения** — он оканчивается на
   `/exec`.

### Шаг 4. Подключи к сайту
1. Открой `index.html`, найди строку `rsvpUrl:` в блоке `CONFIG`.
2. Замени старый адрес на скопированный `/exec`-адрес, например:

```js
rsvpUrl: "https://script.google.com/macros/s/ПОСТАВЬ-СЮДА-СВОЙ-КОД/exec",
```

3. Сохрани файл, загрузи на хостинг (GitHub Pages и т.п.).

### Шаг 5. Проверь
Открой сайт на телефоне → нажми «Келемін / Приду» → введи имя → «Жіберу».
Через пару секунд строка появится в Google-таблице.
Если вместо благодарности вышла ошибка — проверь, что в настройках скрипта
стоит **«Доступ для всех»** и адрес `/exec` скопирован целиком.

## 📤 Публикация в интернете
Репозиторий уже настроен на GitHub Pages (есть `.nojekyll`):
**Settings → Pages → Source: main branch → Save**, и сайт откроется по адресу
`https://<имя-пользователя>.github.io/birthday/`.
После каждого изменения нужно просто отправить изменения в GitHub (`git push`).
